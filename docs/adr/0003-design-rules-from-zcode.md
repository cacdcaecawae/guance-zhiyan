# ADR 0003：设计规范来源与裁剪

日期：2026-09-22 · 状态：已采纳

## 背景

需要一套可执行的 UI 规范。ZCode 的 `DESIGN.md` 与 `AGENTS.md`（zai-org/ZCode，2026-09-22 读取）提供了成熟的 tokens、字号与圆角规则组织方式。

## 决定

采用并裁剪为本项目 `DESIGN.md`：

- 保留：语义颜色 tokens、`text-ui-xl/lg/base/caption/sm/xs` 字号体系（基准 14px）、4px 间距节奏、按可见容器嵌套递减的圆角规则、克制的阴影与动效、控件状态与无障碍要求
- 去除：Zai 主题变体、桌面窗口框架、工作流时间线、Diff / 终端、多进程与远程控制等与本项目无关的规则
- 简化：不使用 `rounded-2xl` 与 `rounded-full`；仅浅色 / 深色 / 跟随系统三种主题

`AGENTS.md` 借鉴其“源码为准、先调查后修改、保留无关改动、如实报告检查结果”的组织方式，去掉上游包结构与脚本。

## 后果

- 后续开发以本地 `DESIGN.md` 为准，不自动跟随上游变化
- 不搬运 ZCode 的品牌素材与业务模块
